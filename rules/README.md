# 规则资产

此目录未来存放获准纳入版本管理的制度、模板、组套和字典映射；当前没有临床生效规则。

本目录负责院内制度和业务规则的版本，不存放医学模型或患者事实。医学判断组件的接口与生成者版本见 [架构文档](../docs/architecture.md#模块与合同归属)；业务工作流的资料范围与复核门槛由 `workflows/` 维护。

每份规则需要适用对象、触发事件、输入事实、产物要求、时限/例外、来源、有效版本及临床审核人。“十八项核心制度”按院内当前文件映射，不在无来源情况下写死时限。院内私有内容按授权选择私有资源存储；不要将患者事实放在规则包。

候选更新先产生差异，审阅后才能替换生效版本。详见 [规则维护](../docs/workflows.md)。
